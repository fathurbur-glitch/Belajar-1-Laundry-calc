# FT-06 WhatsApp Deep Link Button

Sumber PRD: Bagian 5 (BL-03), Bagian 6 (FT-06), Bagian 7 (Format Template WhatsApp), Bagian 8 (AC-04), Bagian 9 (TC-05)

## Tujuan
Pengguna dapat memvalidasi seluruh data pesanan lalu membuka WhatsApp berisi rincian pesanan terformat otomatis dengan satu kali klik.

## Alur
1. Pengguna menekan tombol `Kirim ke WhatsApp`.
2. Sistem memeriksa berat (`> 0`), nama (`tidak kosong`), dan alamat (`tidak kosong` bila antar-jemput aktif).
3. Jika ada error, pengiriman dibatalkan, pesan error ditampilkan, dan fokus diarahkan ke kolom error pertama.
4. Jika semua valid, sistem menyusun teks sesuai template WhatsApp PRD, melakukan `encodeURIComponent`, dan membuka tautan `https://wa.me/<STORE_WA_NUMBER>?text=<ENCODED_MESSAGE>` di tab baru (`_blank`, `rel="noopener"`).
5. Sistem juga menampilkan konfirmasi singkat beserta pratinjau/tautan cadangan jika jendela tab baru diblokir oleh pengaturan browser pengguna.

## Data
- `STORE_INFO.whatsapp_number` (`6281234567890`)
- Data pesanan lengkap: layanan terpilih, berat aktual, berat ditagih, status antar-jemput & pewangi, nama, alamat, catatan, total estimasi.

## Aturan dan rumus
- Template pesan WhatsApp wajib sama persis dengan PRD Bagian 7:
```
Halo Admin Laundry, saya ingin memesan layanan laundry dengan rincian berikut:

*Nama:* [Nama Pelanggan]
*Layanan Utama:* [Cuci Lipat / Cuci Setrika / Cuci Setrika Ekspres]
*Estimasi Berat:* [X] kg (Berat Ditagih: [Y] kg)
*Layanan Tambahan:*
- Antar-Jemput: [Ya (+Rp 10.000) / Tidak]
- Pewangi Premium: [Ya (+Rp Z.000) / Tidak]

*Alamat Penjemputan:* [Alamat Lengkap / "Antar Sendiri ke Toko"]
*Catatan Khusus:* [Catatan khusus atau "-"]

*Estimasi Total Biaya:* *Rp [Total]*

_(Catatan: Total di atas adalah estimasi awal. Berat pasti akan ditimbang kembali saat pakaian diterima oleh kasir/kurir laundry)._

Mohon konfirmasi pesanan dan ketersediaan jadwalnya. Terima kasih!
```
- Nilai pada pesan harus identik dengan nilai yang tampil di layar (format berat Indonesia dengan koma tanpa nol berlebih, format rupiah `Rp 61.000`).
- Seluruh pesan di-encode menggunakan `encodeURIComponent`.
- Pembukaan tautan menggunakan elemen tautan atau `window.open(..., '_blank', 'noopener,noreferrer')`? Catatan runtime: hindari `window.open` jika diblokir iframe; gunakan elemen `<a>` atau klik tautan `<a href={...} target="_blank" rel="noopener noreferrer">` setelah validasi atau tampilkan tautan buka ulang jika diperlukan. Cara paling aman di browser & iframe adalah membuat/memicu `<a target="_blank" rel="noopener">` yang sah saat user click, dan juga menyediakan tautan langsung jika browser memblokir popup!

## Input dan validasi
- Tombol utama `Kirim ke WhatsApp` selalu dapat ditekan agar pengguna mendapat umpan balik error yang jelas jika ada kolom belum lengkap (sesuai TC-03 dan TC-04).

## Tampilan dan teks
- Label tombol: `Kirim ke WhatsApp` (3 kata, tanpa panah)
- Saat tautan WhatsApp disiapkan/dibuka, tampilkan pesan status berhasil (hijau `-800` dan `-50` dengan ikon) berisi tautan langsung `Buka WhatsApp lagi` jika tab baru tidak otomatis terbuka di browser pengguna.

## Kasus uji
| ID | Input | Hasil yang diharapkan | Sumber |
| :--- | :--- | :--- | :--- |
| AC-04 | Data lengkap valid, tombol ditekan | URL `https://wa.me/6281234567890?text=...` dibuka dengan angka dan layanan sama persis seperti di layar | PRD AC-04 |
| TC-05 | Catatan berisi `Baju dinas & sutra, jangan dicampur!` | Karakter `&` dan `!` ter-encode aman (`%26`, `%21`) dan tidak memutus parameter `text` | PRD TC-05 |
| TC-03 & TC-04 | Berat `0` atau alamat kosong saat antar-jemput aktif | Tautan WhatsApp tidak dibuka, fokus pindah ke kolom error pertama | PRD TC-03, TC-04 |
| FT06-04 | Antar-jemput tidak dipilih dan catatan dikosongkan | Pesan memuat `Antar Sendiri ke Toko` dan catatan `-` | Tambahan |

## Di luar lingkup
- Pengiriman pesan otomatis melalui WhatsApp Business API di server.
- Pelacakan status pengiriman pesan setelah keluar dari browser.
