# FT-02 Input Berat & Notifikasi Min. Charge

Sumber PRD: Bagian 5 (BL-01), Bagian 6 (FT-02), Bagian 8 (AC-01), Bagian 9 (TC-01, TC-03), Bagian 11 (store_info.minimum_charge_kg)

## Tujuan
Pengguna dapat memasukkan estimasi berat cucian dan langsung melihat apakah ketentuan minimum charge 3 kg diberlakukan.

## Alur
1. Saat halaman dibuka, kolom berat berisi nilai awal `3` kg.
2. Pengguna mengetik angka berat (memakai titik atau koma) atau menekan tombol `-` dan `+` dengan langkah `0,1` kg.
3. Sistem menghitung berat ditagih: jika berat aktual valid (`> 0`) dan di bawah `3` kg, berat ditagih ditetapkan `3` kg dan notifikasi minimum charge muncul.
4. Jika kolom dikosongkan atau diisi `0` / negatif, estimasi ditandai belum valid dan pengiriman pesanan dicegah saat validasi kirim.

## Data
- `STORE_INFO.minimum_charge_kg` (`3.0`)
- `WEIGHT_STEP` (`0.1`)
- `DEFAULT_WEIGHT_KG` (`3`)

## Aturan dan rumus
- Input berat aktual ($W_{aktual}$) menerima koma (`,`) dan titik (`.`) sebagai pemisah desimal.
- Berat valid jika berupa angka berhingga dan $W_{aktual} \ge 0.1$ (atau $> 0$).
- Rumus PRD BL-01:
  $$W_{ditagih} = \max(3.0, W_{aktual})$$
- Kondisi batas:
  - Jika $0 < W_{aktual} < 3.0$: tampilkan notifikasi visual bahwa ketentuan minimum charge 3 kg diberlakukan.
  - Jika $W_{aktual} \le 0$ atau kosong/tidak valid: $W_{ditagih} = 0$, subtotal menjadi `Rp 0`, dan form tidak mengizinkan pengiriman ke WhatsApp (`TC-03`).

## Input dan validasi
- Kolom input: wajib, `inputMode="decimal"`, label terlihat `Estimasi berat (kg)`.
- Tombol bantu: kurangi `0,1` kg dan tambah `0,1` kg (area sentuh minimal `44 x 44 px`).
- Pesan error saat dikirim atau setelah input tidak valid: `Masukkan berat cucian minimal 0,1 kg, contoh: 2,5.`

## Tampilan dan teks
- Judul bagian: `Masukkan berat cucian`
- Label kolom: `Estimasi berat (kg)`
- Notifikasi saat $0 < W_{aktual} < 3.0$ (latar `bg-amber-50`, teks `text-amber-800`, disertai ikon info):
  `Berat di bawah 3 kg dihitung minimal 3 kg.`
- Penjelasan ringkas di samping/bawah: `Berat ditagih: [Y] kg`

| ID | Input | Hasil yang diharapkan | Sumber |
| :--- | :--- | :--- | :--- |

| Kasus A | Berat `1,8` kg pada `Cuci Setrika Ekspres` (`Rp 15.000/kg`) | Berat ditagih `3` kg, biaya utama `Rp 45.000` | PRD Bagian 5 |

## Di luar lingkup
- Pembulatan berat fisik di luar rumus `max(3.0, W_aktual)`.
- Pemilihan jenis pakaian satuan (kiloan saja sesuai PRD).
